## Descripción del proyecto

LabPresta permite registrar equipos y usuarios, y controlar los préstamos y las devoluciones para conocer en todo momento dónde se encuentra cada equipo.

## Requisitos

- Java JDK 21 o superior.

## Cómo ejecutar la aplicación

1. Verificar que Java 21 o una versión superior esté instalado.
2. Abrir la carpeta `dist`.
3. Comprobar que dentro de `dist` estén el archivo `labpresta-1.0-SNAPSHOT.jar` y los archivos CSV de datos (`equipos.csv`, `usuarios.csv` y `prestamos.csv`).
4. Abrir una terminal en la carpeta `dist`.
5. Ejecutar:

```bash
java -jar labpresta-1.0-SNAPSHOT.jar
```
